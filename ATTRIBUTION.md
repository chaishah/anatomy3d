# Attribution and model licensing

This application code is a separate web viewer prototype. The skeletal and cardiovascular anatomy models are loaded from the upstream Z-Anatomy GitHub repository at runtime and are not bundled into this repository.

For model-derived content, preserve the upstream attributions:

- **BodyParts3D - The Database Center for Life Science - CC-BY-SA 2.1 Japan**
- **Z-Anatomy - The open source atlas of anatomy - CC-BY-SA 4.0**

The upstream Z-Anatomy model license also notes additional incorporated assets that may carry separate licenses, including content from the University of Washington and University of Dundee. Before bundling or redistributing any extracted head, vascular or skull-base asset, review the exact upstream licensing for the included structures and retain all required attribution/share-alike terms.

## Written educational summaries

The app contains original short-form anatomy summaries based on standard anatomy references. Structure-specific source links point primarily to NCBI Bookshelf/StatPearls pages. These summaries are provided for educational reference and are not medical advice.
